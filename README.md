# ZVPN

ZVPN
是憨豆团队基于多年"一键翻墙"产品与服务经验，倾力打造的一款专为中国大陆地区用户设计的
VPN 产品。

ZVPN 集高度安全与极简易用于一身，采用最新 VPN
技术与安全设计，并为中国大陆的同胞提供免费基础服务。

## 主要特点

### 🎁 免费服务，无需注册

ZVPN 为中国大陆的同胞提供免费基础服务。

无需注册账号，下载安装即可立即使用。

### ⚡ 极简易用

一键启动，几秒之内连接自由世界。

无需任何配置。您需要做的，只是点击一下“启动按钮”，就这么简单！

### 🔒 尊重隐私

我们不需要您的邮箱，也不需要您的手机号，您根本无需填写任何个人资料。

最安全的个人信息保护，就是从未被收集。ZVPN 从产品设计之初就决定：我们的服务绝不能依赖于用户的任何个人信息。

### 🛡️ 高性能、高安全设计

ZVPN 采用现代高性能 VPN 协议与先进网络技术，提供稳定、快速、可靠的连接体验，并持续针对复杂网络环境进行优化。

产品采用多层安全机制，尤其关注高风险网络环境下可能面临的网络监听、流量分析及其他潜在安全风险，致力于为用户提供更加安全、可以信赖的网络访问体验。

ZVPN 高度重视用户隐私与数据安全，坚持尽可能减少服务数据的收集。
